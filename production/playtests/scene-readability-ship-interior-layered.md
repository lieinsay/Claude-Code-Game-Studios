## 体验反馈问题

| 问题 | 期望 | 反馈 / 修改点 |
| --- | --- | --- |
| 我在哪里？ | 能快速读出这是飞船内部，且能区分驾驶舱、货舱、轮机间或走廊。 |  |
| 我在这里能做什么？ | 舵轮、情报、货物、模块、维修等核心行动能从空间锚点读出。 |  |
| 我如何离开或继续？ | 舱门、航行入口、返航/离船路径可见或可通过舱段锚点发现。 |  |
| 什么发生了变化？ | 船体损伤、货物、模块、生活痕迹等状态变化能在船内空间看见。 |  |
| 分层和遮挡可读吗？ | 水平场景的层级、前景遮挡、设备背后通行和 behind-object reveal 不让玩家迷路或丢失角色。 |  |
| UI/HUD 是否只是辅助？ | UI 不替代船内空间身份。 |  |
| 场景是否符合预期幻想？ | 船内像“家”和整备空间，而不是一组功能面板。 |  |
