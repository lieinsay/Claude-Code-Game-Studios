## 体验反馈问题

| 问题 | 期望 | 反馈 / 修改点 |
| --- | --- | --- |
| 我在哪里？ | 能快速读出这是赭色小型资源岛，而不是旧集市、雾灯残骸或通用空岛。 |  |
| 我在这里能做什么？ | 条带状铁矿是可识别的资源点，玩家能理解可以靠近并采集 / 获取资源。 |  |
| 我如何离开或继续？ | 返航点和起飞返回流程可见，不能只是画面切换。 |  |
| 什么发生了变化？ | 采集后矿脉或反馈能说明资源已获取 / 不可重复获取。 |  |
| UI/HUD 是否只是辅助？ | UI 只显示资源 / 容量 / 提示，不能替代条带状铁矿或岛屿身份。 |  |
| 场景是否符合预期幻想？ | 赭石岛像一个短暂停靠的小型资源岛，而不是完整矿场、市场或战斗场。 |  |
