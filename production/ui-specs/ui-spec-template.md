## 11. 用户审核清单

- [ ] 创建适合性人工审查已记录，结论为 `APPROVED` 或 `APPROVED_WITH_NOTES`。
- [ ] 审查人确认不能复用现有 HUD / 面板 / 模态解决。
- [ ] 人工备注已写回本规格、story 或后续任务。
- [ ] 这个 UI 是否真的需要常驻或弹出。
- [ ] 打开方式是否符合直觉：自动、绑定世界锚点、快捷键或系统事件。
- [ ] 显示优先级是否合理，不会抢走更重要的信息。
- [ ] UI 是否只做解释、选择、确认、反馈，没有替代世界对象或场景本体。
- [ ] 关闭、取消、失败和禁用反馈是否清楚。
- [ ] 不看这个 UI 时，核心场景身份和世界锚点仍然成立。
