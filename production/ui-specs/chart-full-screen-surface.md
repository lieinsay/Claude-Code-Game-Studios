## 1. UI 身份

- UI 是什么: 从船内航图台打开的全屏或近全屏航图选择表面。
- 玩家为什么需要它: 出航前选择目的地 / 航线，查看基础风险和确认是否起飞。
- 它服务哪个系统 / 场景 / 单位: Chart、Navigation、Hub；绑定 `scene_unit.prototype.chart_table`。
- 它不是什么: 不是旧 `ChartPanel`，不是航行大场景，不证明岛屿本体存在。

## 2. 显示分类与打开方式

| 字段 | 内容 |

| UI 分类 | `full_screen_surface` |

## 3. 显示优先级与覆盖规则

| 情况 | 规则 |
| --- | --- |
| 更高优先级 UI 打开 | 航图暂停或关闭，并在返回后恢复安全状态 |
| 同优先级 UI 同时请求 | 出航确认、容量取舍等按领域状态排队，不能同时抢焦点 |
| 更低优先级 UI 已打开 | 航图打开时低优先级 HUD / hint 降级或隐藏 |
| 关闭后恢复 | 返回 `ship_interior_layered`，玩家仍位于航图台附近 |
| 数据变更时刷新 | 航线、目的地和风险摘要必须从 Chart / Navigation 数据刷新 |

## 4. 内容与作用

| 内容区域 | 显示什么 | 数据来源 | 玩家动作 | 禁止用途 |
| --- | --- | --- | --- | --- |
| 目的地列表 | 可选岛屿 / 航线 | Chart / authored routes | 选择目的地 | 不证明岛屿场景已实现 |
| 风险摘要 | 路上危险、航程、返航提示 | Navigation / route data | 阅读 | 不承包实际航行玩法 |
| 确认区 | 起飞 / 返回 | Hub / Chart state | 确认或取消 | 不直接跳过航行大场景 |

## 5. 输入与焦点

| 输入 | 行为 | 可用条件 | 失败 / 禁用反馈 |
| --- | --- | --- | --- |
| 方向 / 鼠标 | 切换航线 | 航线可用 | 不可用航线显示原因 |
| Enter / Use | 确认选择或起飞 | 有有效选择 | 提示先选择航线 |
| Esc | 返回船内 | 非不可逆提交中 | 返回航图台附近 |

- 初始焦点: 第一条可用航线。
- Tab 顺序: 目的地 -> 风险摘要 -> 确认 -> 返回。
- Esc 行为: 可逆状态返回船内。
- 模态时焦点是否锁定: 是。

## 6. 布局与遮挡边界

- 默认位置: 全屏 / 近全屏。
- 最大屏幕占比: 可接管屏幕，但必须明确这是 UI 表面而非世界场景。
- 是否允许遮挡世界身份: 允许暂时遮挡，但关闭后必须恢复船内航图台场景。
- 是否允许遮挡核心交互锚点: 只在航图打开期间允许。
- 与 HUD / 模态 / toast 的层级关系: 高于常驻 HUD，低于 P0 危机 / 致命错误。

## 7. 状态与生命周期

| 状态 | 进入条件 | 显示 | 输入规则 | 退出条件 |
| --- | --- | --- | --- | --- |
| hidden | 默认 | 无 | 世界输入正常 | 航图台 Use |
| active | 航图打开 | 航线 / 风险 / 确认 | UI 接管输入 | Esc 或确认 |
| disabled | 无可用航线或系统阻止 | 禁用原因 | 只允许返回 | 状态恢复 |
| closing | 返回船内 | 过渡反馈 | 输入短暂隔离 | 船内恢复 |

## 8. 数据与运行时合同

- 读取的领域管理器: Chart、Navigation、Hub。
- 会调用的领域 API: 选择航线、确认起飞、取消返回。
- 持久化字段: 当前选择和 screen state，按现有 progress 规则处理。
- 信号 / 语义事件: chart_opened、route_selected、departure_confirmed。
- 不允许写入的状态: 不直接写资源、市场、采矿、修复或战斗状态。
