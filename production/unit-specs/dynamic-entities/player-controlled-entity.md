## 2. 单位身份

- 单位是什么: 当前可玩切片中由玩家操作、可移动、可触发空间交互的世界实体。
- 玩家 3 秒内应如何识别: 玩家应能看出这是自己在场景中的位置和可操作对象；本轮可以是可移动图片或清晰标记。
- 它服务的场景幻想 / 功能: 让玩家真实存在于初始岛屿、船内和离岛场景中，而不是只通过 UI 或摄像机状态存在。
- 它不是什么: 不是 HUD 光标、调试点、摄像机锚点，也不是完整角色动画 / 战斗 / 成长系统。

## 5. 状态与生命周期

| 状态 | 进入条件 | 世界表现 | 玩法影响 | 退出条件 |
| --- | --- | --- | --- | --- |
| spawned | 场景载入 | 玩家实体出现在合法出生点 | 可接收世界输入 | 场景切换或输入锁定 |
| active | 世界输入可用 | 实体响应移动和交互 | 驱动移动、Use 和场景锚点触发 | 模态 UI 打开或场景切换 |
| restored | 存档 / 场景切换返回 | 恢复到合法位置 | 防止玩家丢失或越界 | 下一帧进入 `active` |
| blocked | 输入焦点被 UI 锁定或位置非法 | 停止移动或回退到安全点 | 阻止错误交互 | 焦点恢复或复位完成 |

## 6. 交互规则

| 玩家动作 | 输入 / 焦点规则 | 成功结果 | 失败 / 禁用反馈 | UI 辅助 |
| --- | --- | --- | --- | --- |
| 移动 | 世界输入未被模态 UI 抢占 | 实体位置改变 | 输入锁定时保持原地 | HUD 可显示状态，不替代实体 |
| Use / 交互 | 玩家在世界锚点范围内 | 触发单位、场景或 UI 打开请求 | 显示短提示或无效反馈 | UI 只能解释失败原因 |

## 7. 固定 / 实体专属规则

- 运动来源: 玩家输入。
- 运行时状态: 位置、当前场景、交互范围、输入锁定、恢复点。
- 碰撞响应: 与阻挡物分离；交互范围使用 soft overlap。
- 安全复位: 掉出边界、卡住或离开有效 floor/layer 时回到场景安全点或最近合法位置。
- 是否持久化位置 / 速度 / 状态: 本轮至少持久化场景恢复所需位置；速度、动画、战斗和携带状态后续审批。

固定单位规则: `N/A true`，本文件只覆盖动态实体。
