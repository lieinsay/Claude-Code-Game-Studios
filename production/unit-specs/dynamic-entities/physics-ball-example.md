# 可弹开物理球单位规格示例

> **Unit ID**: `scene_unit.prototype.example_physics_ball`
> **单位名称**: 可弹开物理球
> **单位分类**: `dynamic_entity`
> **存放目录**: `production/unit-specs/dynamic-entities/`
> **生命周期状态**: spec_drafted 示例
> **来源 GDD**: `design/gdd/scene-physics-unit-system.md`
> **最后更新**: 2026-05-24

## 1. 单位身份

- 单位是什么: 放在地上的可移动球体单位，玩家或其他实体碰到时会滚动或弹开。
- 玩家 3 秒内应如何识别: 能看出它是会受碰撞影响的球，而不是固定装饰或普通资源点。
- 它服务的场景幻想 / 功能: 让场景中的物体有可预测的实体感，可用于轻量谜题、反馈、阻挡或玩具感。
- 它不是什么: 不是 UI 图标、不是不可碰撞装饰、不是自动追踪玩家的敌人。

## 2. 分类与边界

| 字段 | 内容 |
| --- | --- |
| 单位分类 | `dynamic_entity` |
| 存放目录 | `production/unit-specs/dynamic-entities/` |
| 是否可移动 | 是 |
| 是否可交互 | 条件性；默认通过碰撞交互 |
| 是否有状态 | 是 |
| 是否持久化 | 由场景决定；谜题球通常持久化，玩具球可重置 |
| 领域 owner | Player Movement / Scene Physics，若是谜题则由对应玩法系统拥有结果 |
| 表现 owner | Scene Composition / Feedback |
| UI 是否可替代本体 | 否 |

## 3. 物理合同

| 字段 | 内容 |
| --- | --- |
| 碰撞类型 | `blocking_dynamic` 或 `pushable` |
| 遮挡层 | `midground_object` |
| 比例规则 | 0.35-0.8x `player_unit`，除非作为大型障碍 |
| 可通过性 | 默认不可穿过，但可推动 / 弹开 |
| 特殊表面 | 可与 `slippery`、`conveyor`、`water_shallow` 等表面组合 |
| 动态行为标签 | `elastic`，可选 `slippery` |
| 恢复规则 | 掉出边界、卡进墙、长时间静止在无效区时回到最近安全点 |

## 4. 状态与生命周期

| 状态 | 进入条件 | 世界表现 | 玩法影响 | 退出条件 |
| --- | --- | --- | --- | --- |
| `idle` | 初始或停止 | 静止球体 | 可被碰撞推动 | 受到碰撞 |
| `rolling` | 受到低到中等冲量 | 滚动、摩擦减速 | 可撞开轻物体或触发压力点 | 速度低于阈值 |
| `bouncing` | 受到高冲量或撞到弹性表面 | 弹跳、短暂离地影子 | 可能越过小障碍或撞出危险 | 弹跳次数或速度低于阈值 |
| `stuck_recovering` | 卡住或掉出边界 | 闪烁、淡出或回收反馈 | 暂停交互 | 回到安全点 |

## 5. 交互规则

| 玩家动作 | 输入 / 焦点规则 | 成功结果 | 失败 / 禁用反馈 | UI 辅助 |
| --- | --- | --- | --- | --- |
| 碰撞 / 推动 | 玩家移动体接触球体 | 球按碰撞方向和力度滚动或弹开 | 被模态 UI 阻断时世界输入不生效 | 无，或首次提示“可推动” |
| 使用 / 拾取 | 仅当场景允许 | 拾起或锁定球体 | 太远、球体过重、当前状态不允许 | 可显示原因 |

## 6. 实体单位专属规则

- 运动来源: 玩家推动、碰撞冲量、地形表面和可选脚本力。
- 运行时状态: 位置、速度、朝向、当前 floor/layer、是否卡住。
- 碰撞响应: 按碰撞方向滚动；高冲量进入 `bouncing`；无效碰撞不能穿墙。
- 安全复位: 掉出边界、卡住、离开有效 floor/layer 时回到 `safe_reset_position`。
- 是否持久化位置 / 速度 / 状态: 谜题球持久化位置和状态；玩具球可只持久化初始状态并在重进场景时重置。

## 7. 场景使用规则

| 场景 | 使用方式 | 实例要求 | 是否需要用户审核 |
| --- | --- | --- | --- |
| 训练 / 起点场景 | 玩具感或物理教学 | 必须不阻塞关键路径 | 是 |
| 探索场景 | 轻量谜题、压力点、噪音风险 | 必须声明失败恢复和卡死处理 | 是 |

## 8. 作者化数据要求

- 原型 ID: `scene_unit.prototype.example_physics_ball`
- 允许场景: 由具体场景规格决定。
- 必需实例字段: `instance_id`、`scene_id`、`position`、`floor_id`、`scene_spec`、`initial_state`、`safe_reset_position`。
- 可覆盖字段: 质量、弹性、摩擦、最大速度、是否可拾取、是否持久化。
- 不允许实例静默覆盖的字段: UI 证据边界、碰撞类型、卡死恢复要求。
- 运行时验证 hook: 碰撞响应 smoke、边界恢复 smoke、状态持久化测试。
