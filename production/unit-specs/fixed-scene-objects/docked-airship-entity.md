# 停靠飞船实体单位规格

> **Prototype IDs**: `scene_unit.prototype.hub_docked_ship_hull`, `scene_unit.prototype.hub_airship_envelope`
> **单位名称**: 停靠飞船实体 / 云织号外部轮廓
> **单位分类**: `fixed_scene_object`
> **生命周期状态**: `spec_drafted`
> **创建适合性人工审查**: `APPROVED`
> **来源 GDD**: `design/gdd/airship-hub.md`, `design/gdd/scene-physics-unit-system.md`
> **最后更新**: 2026-05-24

## 1. 单位身份

- 单位是什么: 初始岛屿上停靠的飞船本体，由船体和飞艇气囊 / 轮廓共同构成。
- 玩家 3 秒内应如何识别: 玩家应能看出“飞船停在岛上”，并理解登船、起飞、返航的空间关系。
- 它服务的场景幻想 / 功能: 飞艇是家，不只是载具；玩家从真实世界对象登船，而不是从按钮进入下一屏。
- 它不是什么: 不是航图 UI、不是旧 `ChartPanel`、不是完整维修 / 模块 / 部件系统。

## 3. 物理合同

| 字段 | 内容 |
| --- | --- |
| 碰撞类型 | 船体为 `blocking_static`；气囊为高层轮廓 / height marker，第一版不承载玩法碰撞 |
| 遮挡层 | 船体为前景 / 中景；气囊为高层轮廓 |
| 比例规则 | 船体和气囊必须明显大于玩家，并能作为初始岛屿主地标 |
| 可通过性 | 船体不可穿过；登船通道由 `hub_boarding_ramp` 或后续入口单位表达 |
| 特殊表面 | N/A true |
| 动态行为标签 | `docked_airship_landmark` |
| 恢复规则 | 返航后恢复为停靠可读状态；不得由航图 UI 独立证明飞船存在 |

## 4. 状态与生命周期

| 状态 | 进入条件 | 世界表现 | 玩法影响 | 退出条件 |
| --- | --- | --- | --- | --- |
| docked | 初始岛屿可玩或返航完成 | 船体和气囊可见，登船路径可读 | 玩家可找到登船 / 出发关系 | 起飞流程开始 |
| boarding_available | 玩家靠近登船路径 | 船体旁入口 / 坡道可用 | 可进入船内 | 玩家离开范围或切换船内 |
| departure_pending | 航图 / 起飞流程确认后 | 飞船仍可读，但世界输入可能隔离 | 进入起飞过渡 | 进入航行大场景 |
| unavailable | 更高优先级状态阻止登船 | 船体不消失，显示禁用反馈 | 阻止错误切换 | 状态恢复 |

## 5. 交互规则

| 玩家动作 | 输入 / 焦点规则 | 成功结果 | 失败 / 禁用反馈 | UI 辅助 |
| --- | --- | --- | --- | --- |
| 靠近飞船 | 世界输入可用 | 读出登船路径和船体边界 | 无 | 可显示短提示 |
| 登船 | 玩家位于坡道 / 入口范围 | 切换到 `ship_interior_layered` | 若不可用，显示原因 | UI 只能提示，不替代入口 |
| 起飞 | 由船内航图 / 起飞流程触发 | 进入起飞过渡和航行大场景 | 若状态阻止，显示原因 | 航图 UI 不能直接跳过航行场景 |

## 6. 固定单位规则

- 固定原因: 停靠飞船是初始岛屿地标和登船关系的世界证据。
- 位置是否可被场景实例覆盖: 可由 `hub_island_dock` 摆放实例决定。
- 是否可破坏 / 开关 / 采集 / 再生: 本轮 N/A true。
- 状态变化是否改变碰撞或遮挡: 本轮不改变；起飞过渡由场景流程表达。
- 是否需要 `behind_object_reveal`: 第一版 N/A true。
- 是否会生成资源、实体或交互锚点: 不直接生成；登船锚点由坡道 / 入口单位承载。

实体单位规则: `N/A true`，本文件只覆盖固定单位。

## 7. 场景使用规则

| 场景 | 使用方式 | 实例要求 | 是否需要用户审核 |
| --- | --- | --- | --- |
| `initial_island_scene` / `hub_island_dock` | 初始岛屿地标、登船关系、出发前飞船读法 | 船体、气囊、坡道和玩家路径必须在同一空间关系中可读 | 不再审核“是否需要飞船”；只审核规格是否忠实记录范围 |
| `voyage_open_world_scene` | 起飞后由航行场景表达飞船运动 | 停靠实体不直接复用为航行控制体 | 航行视角需独立二审 |
