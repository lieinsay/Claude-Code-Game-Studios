## 14. 就绪检查清单

- [ ] 创建适合性人工审查已记录，结论为 `APPROVED` 或 `APPROVED_WITH_NOTES`。
- [ ] 用户已确认需要独立单位，而不是已有单位的状态、皮肤或摆放实例。
- [ ] 若涉及不合规旧 Godot 节点，删除前已询问用户并记录结论。
- [ ] 独立实现 / 资产边界已明确，不能只混入旧大场景、大脚本或临时节点。
- [ ] 单位分类、目录、物理合同和 UI 边界一致。
- [ ] 状态变化可读，不需要靠 UI 独自解释。
