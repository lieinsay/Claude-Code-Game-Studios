# Interaction Pattern Library — 交互模式库

> **Status**: Active
> **Source**: Extracted from Hub, Chart, Exploration UX Specs
> **Last Updated**: 2026-05-05
> **Purpose**: 为 UI 程序员和 UX 设计师提供可复用的交互模式参考。所有新屏幕的交互设计应优先使用已有模式；如需新模式，须先添加到此库中。

---

## 1. Approach + E — 靠近交互

**使用场景**: Hub 站点交互、探索搜点/情报点/威胁点、提取锚点

**触发条件**: 玩家角色进入交互目标的触发半径（通常 1-2 单位）

**行为**:
1. 交互提示 `[E] 动作名` 出现在目标上方
2. 玩家按 `E` → 执行交互
3. 交互完成 → 提示消失

**变体**:
| 变体 | 提示文本 | 屏幕 |
|------|---------|------|
| 站点交互 | `[E] 使用` / `[E] 交谈` / `[E] 休息` | Hub |
| 搜索 | `[E] 搜索` | Exploration |
| 调查 | `[E] 调查` | Exploration |
| 提取 | `[E] 提取` | Exploration (锚点) |

**设计约束**:
- 同一时间仅高亮最近的交互目标（InteractionRegistry 优先级仲裁）
- 提示文字始终可见（不被玩家角色遮挡）
- 交互目标有焦点高亮（航标青 `#4FB7B2` 轮廓，2px）

**无障碍**: 键盘 `E` 和鼠标点击均可触发。交互目标有清晰的视觉焦点指示。

## 2. WASD + Click-to-Move — 双重移动

**使用场景**: Hub 内部移动、探索区域移动

**触发条件**: 始终可用（战斗结算期间除外）

**行为**:
- `W/A/S/D`: 八向移动，受地形/碰撞体边界限制
- 鼠标点击地面: 玩家向点击位置移动（寻路/直线）
- 鼠标点击交互目标: 玩家移动至目标 + 自动触发交互

**设计约束**:
- 键盘和鼠标输入共享同一移动状态——不产生冲突
- 移动速度由系统配置（探索和 Hub 可使用不同速度）
- 碰撞体停止由 Godot `CharacterBody2D.move_and_slide()` 处理

**无障碍**: 完整键盘操作支持——移动不依赖鼠标。

## 3. Tab Overlay — 覆盖层面板

**使用场景**: 背包查看、物品管理

**触发条件**: 玩家按 `Tab`（Hub 或探索中均可）

**行为**:
1. 按 `Tab` → 背包覆盖层从屏幕侧边滑入（右侧，350px 宽）
2. 覆盖层显示当前携带物品列表（图标 + 名称 + 数量）
3. 按 `Tab` 再次或点击覆盖层外 → 覆盖层关闭
4. 覆盖层打开时游戏暂停（探索）/ Hub 交互锁定

**变体**:
| 变体 | 触发 | 内容 |
|------|------|------|
| 背包 (S6a) | `Tab` | 物品列表 + 容量指示器 |
| 物品详情 (S6b) | `I` 或点击物品 | 选中物品的完整描述 |

**设计约束**:
- 覆盖层为模态——打开时阻止底层交互
- 覆盖层打开期间 HUD 保持可见（Pool 5、船体状态）
- 动画: 滑入 0.25s ease-out，滑出 0.2s ease-in

**无障碍**: 键盘 `Tab` 切换打开/关闭。焦点在覆盖层内循环。

## 4. Esc Pause — 通用暂停

**使用场景**: 所有屏幕（Hub、Chart、Exploration）

**触发条件**: 玩家按 `Esc`

**行为**:
1. 按 `Esc` → 暂停菜单从中心淡入（0.2s）
2. 游戏时间暂停（`get_tree().paused = true`，探索暂停标记）
3. 暂停菜单选项: 继续、保存、设置、返回主菜单
4. 按 `Esc` 再次或点击"继续" → 恢复

**变体**:
| 场景 | 行为差异 |
|------|---------|
| Hub | 所有站点交互锁定 |
| Chart | 出航确认锁定后 Esc 不可取消出航 |
| Exploration | 威胁活跃时 Esc 关闭决策面板（如果面板打开），否则打开暂停 |
| 航行过渡 | Esc 不可用 |

**设计约束**:
- 暂停期间不保存——保存需玩家明确选择"保存"选项
- 威胁结算期间（PROCESSING 状态）Esc 输入被忽略

## 5. Confirmation Gate — 确认门

**使用场景**: 出航确认、提取确认、不可逆操作

**触发条件**: 玩家触发一个不可逆操作

**行为**:
1. 玩家触发操作 → 确认弹窗出现（模态）
2. Phase 1: 显示操作摘要 + 后果说明（0.2s pulse）
3. Phase 2: 面板完整显示，两个按钮——"确认"和"取消"
4. 玩家选择"确认" → Phase 3: 锁定动画（不可取消的过渡动画）
5. Phase 4: 黑屏过渡 → 下一场景

**变体**:
| 变体 | 确认后果 | 锁定动画 | 取消后果 |
|------|---------|---------|---------|
| 出航确认 | 消耗资源，航程开始 | 墨水扩散 (1.2s) | 返回航图浏览 |
| 提取确认 | 结束探索，物品结算 | 暖金色渐亮 (1.5s) | 返回探索 |

**设计约束**:
- "确认"按钮默认非焦点——防止误触
- 锁定动画开始后不可取消（terminal state）
- 确认文本必须说明不可逆性: "出航后无法取消，是否确认？"

**无障碍**: 键盘 `Enter` = 确认，`Esc` = 取消（锁定前）。焦点默认在"取消"按钮。

## 6. Decision Breath — 决策呼吸

**使用场景**: 威胁遭遇（Combat #12）

**触发条件**: 玩家接近或触发威胁点

**行为**:
1. 威胁触发 → 屏幕边缘琥珀色脉冲（0.3s）+ 警报音（单次船铃）
2. 决策面板从底部滑入（0.25s ease-out），探索暂停
3. 面板显示: 威胁描述 + 船体状态 + 3 个响应选项
4. **无计时器** — 玩家可以无限时间阅读和决策
5. 玩家可按 Esc 暂时关闭面板查看探索地图（威胁活跃指示器保持在屏幕顶部）
6. 玩家选择选项 → 结算序列（同步，<1 帧）→ 面板关闭

**响应选项设计规则**:
- 选项按安全度分组: 安全选项（蓝/青调）vs 风险选项（橙/红调）
- 不可用选项灰显 + tooltip 说明缺失条件
- 始终有一个"安全阀"选项（撤退）——永不灰显
- 风险选项显示后果预览（伤害范围、概率）

**设计约束**:
- 键盘快捷键 `[E]`/`[T]`/`[R]` 绑定到三个选项——无论面板是否打开均有效
- 面板打开时鼠标点击被面板捕获（不穿透到探索层）
- 一个时间仅一个威胁处于活跃结算状态（队列 FIFO，max depth 4）

**无障碍**: 所有选项可通过键盘快捷键选择。颜色不是唯一的区分方式——同时使用图标和文字。

## 7. State-Driven Visibility — 状态驱动显隐

**使用场景**: Hub 站点可用性、航图路线显示、探索点状态标记

**触发条件**: 游戏状态变化（模块状态、知识状态、探索进度）

**行为**:
- 内容根据游戏状态显示/隐藏/改变外观
- 不可用的内容不隐藏——灰显 + 锁定图标 + tooltip 说明解锁条件
- 状态转换使用动画过渡（淡入/淡出 0.3s），非瞬间切换

**变体**:
| 模式 | 状态 | 视觉效果 |
|------|------|---------|
| 路线可见性 | rumored → identified → verified | 虚线 → 实线 → 暖金发光 |
| 站点可用性 | locked → unlocked | 灰显 + 锁图标 → 正常 + 高亮 |
| 搜点状态 | 未搜索 → 已搜索 | `[?]` 标记 → `[✓]` 标记 |
| 威胁状态 | active → suppressed | 琥珀脉冲点 → 淡出消失 |

**设计约束**:
- 状态驱动的视觉变化必须同时有非颜色编码（图标形状、虚线/实线、标签文字）
- 解锁条件的 tooltip 在 hover 300ms 后出现

## 8. Screen Transition — 屏幕过渡

**使用场景**: Hub ↔ 航图 ↔ 探索 ↔ 航行过渡

**触发条件**: 玩家完成一个屏幕的出口操作

**行为**:
1. 出口动画播放（0.3s-1.5s，取决于过渡类型）
2. 黑屏过渡（0.3s）
3. 目标屏幕加载 + 入口动画播放

**过渡类型**:
| 过渡 | 出口动画 | 黑屏 | 入口动画 | 总时长 |
|------|---------|------|---------|--------|
| Hub → Chart | 舵轮面板展开 | 0.3s | 航图淡入 | 0.8s |
| Chart → 航行 | 墨水扩散锁定 | 0.3s | 航行加载 | 1.8s |
| 航行 → Exploration | — | 0.3s | 场景淡入 + 舱门 | 1.1s |
| Exploration → Hub | 提取暖金渐亮 | 0.3s | Hub 到达动画 | 2.1s |

**设计约束**:
- 过渡总时长 ≤ 500ms（场景切换预算，ADR-0001）
- 加载在后台进行（`ResourceLoader.load_threaded_request`）
- 过渡期间输入被阻止

## 9. HUD Persistence — HUD 常驻

**使用场景**: 探索场景、Hub（部分元素）

**触发条件**: 始终渲染在屏幕顶部或边缘

**常驻元素**:
| 元素 | 位置 | 更新时机 |
|------|------|---------|
| Pool 5 余量条 | 顶部左 | 物品消耗/获得时（0.2s 动画） |
| 侦察效率 | 顶部中 | 模块状态变化时 |
| 船体波段 | 顶部右 | 伤害/修复时（0.3s 动画） |
| 提取方向指南针 | 边缘 | 每帧（指向锚点） |
| 威胁活跃指示器 | 顶部中 | 威胁触发/清除时 |

**设计约束**:
- HUD 始终渲染在游戏视图之上（z-index 最高但低于模态面板）
- HUD 更新使用 dirty-flag 批量更新——不在 `_process()` 中每帧重绘
- HUD 元素不阻挡游戏视图中的交互目标
- 最后 2 格 Pool 5 红色闪烁（1s 周期）——仅视觉，不伴随音频

## 10. Keyboard-First — 键盘优先

**使用场景**: 所有屏幕，所有交互

**设计原则**:
- 每个交互必须有键盘快捷键
- 键盘快捷键在 UI 上以 `[Key]` 标签显示
- 快捷键在相关上下文中保持一致性:
  - `E` = 交互/确认
  - `Tab` = 背包/覆盖层
  - `Esc` = 返回/暂停
  - `W/A/S/D` = 移动
  - `I` = 物品详情
  - `M` = 航图（Hub 中）
  - `Enter` = 确认（弹窗中）
- 鼠标操作为可选的便利方式，不承载独占功能

**验证标准**: 不碰鼠标可完成完整的"Hub → 航图 → 出航确认 → 探索 → 搜索 → 威胁应对 → 提取 → Hub"流程。

## 模式使用指南

### 为新屏幕选择模式

1. 检查此库中是否有匹配的交互模式
2. 若无匹配，判断新交互是否可被已有模式覆盖（扩展变体）还是需要新模式
3. 如需新模式，添加到此库并标注"Proposed"状态
4. UX Review (`/ux-review`) 将检查新屏幕是否正确使用了已有模式

### 模式优先级

| 优先级 | 规则 |
|--------|------|
| **MUST** | 键盘优先（模式 #10）——所有交互必须有键盘路径 |
| **MUST** | 状态驱动的非颜色编码（模式 #7）——满足 WCAG AA |
| **SHOULD** | 不可逆操作使用确认门（模式 #5） |
| **SHOULD** | 模态覆盖层使用 Esc 关闭（模式 #4） |
| **MAY** | 鼠标便利操作作为键盘路径的补充 |
