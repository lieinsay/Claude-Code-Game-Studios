# 无障碍需求 — 云海织航

> **无障碍等级**: Basic (基础)
> **创建日期**: 2026-05-05
> **引擎**: Godot 4.6.2 (Web-first)
> **参考**: WCAG AA (TR-ui-004 已引用对比度要求)

## 等级定义

**Basic 级**聚焦于最低可行无障碍支持：键位重映射 + 字幕。不追求全面覆盖，但确保核心可玩性不被无障碍问题阻断。

### 已承诺

| 需求 | 说明 | 实现点 |
|------|------|--------|
| **键位重映射** | 所有游戏内操作可由玩家重新绑定 | Input Map 通过 Settings 界面暴露；持久化到 `settings.input` 快照包 |
| **字幕** | 所有有意义的音频事件提供文字提示 | 通过 #17 Feedback 语义事件系统分发 `subtitle_requested` 信号；UI 层渲染 |
| **WCAG AA 对比度** | UI 文本和图标满足最低对比度要求 | TR-ui-004；#16 UIManager 的颜色系统 (Section 7 of Art Bible) 预验证 |

### 不承诺（Basic 级范围外）

- 色盲模式（Standard 级）
- 可缩放 UI / 大字体模式（Standard 级）
- 运动无障碍 / 减少动画（Comprehensive 级）
- 屏幕阅读器支持（Comprehensive 级）
- 完全自定义控件 / 外部审计（Exemplary 级）

## 设计约束

1. **键位重映射界面** 必须在主菜单和暂停菜单中可访问
2. **Input Map** 不得在代码中硬编码键位 — 始终通过 `InputMap` API 读取
3. **字幕** 对以下事件为必需：NPC 对话、威胁预警、修复完成提示、伙伴状态变更
4. **颜色不是唯一的信号载体** — 任何颜色编码的信息必须有第二通道（形状、图标、文字）

## 已知限制

- Godot 4.6 Web 导出不支持系统级屏幕阅读器 API（AccessKit 4.5 为桌面专用）
- Web 浏览器自带缩放会改变 Canvas 渲染分辨率，不保证 UI 布局一致性
- MVP 阶段不开发专门的无障碍设置界面 — 键位重映射使用 Godot 内置 Input Map 对话框

## 审查计划

- 首次原型完成后，验证键位重映射是否覆盖所有游戏内操作
- 首次有音频内容的构建中，验证字幕信号触发完整性
- Pre-Production 阶段不要求无障碍专项测试
